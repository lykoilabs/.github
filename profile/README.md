# Lykoi Labs

A small studio in Taiwan building open-source infrastructure for persistent
online worlds.

## Projects

| | |
|---|---|
| [**天守 Tenshu**](https://github.com/lykoilabs/tenshu) | A modern MMO server engine in Rust: zone actors, fixed-tick ECS simulation, per-client interest budgets, and a protocol-terminating gateway tier. Pre-alpha. |

Documentation will live at [tenshu.lykoilabs.dev](https://tenshu.lykoilabs.dev)
once there is something to document.

## Principles

- **Clean room.** Everything here is original work under MIT OR Apache-2.0.
  No game client data, no reverse-engineered material and no copyleft
  derivatives are accepted, in any repository.
- **Operable.** Metrics, traces, load bots and a deployment story ship with
  the first milestone, not after.
- **Boring where it can be.** PostgreSQL, Kubernetes, OpenTelemetry. The
  novelty budget is spent on the simulation.
