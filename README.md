# lykoilabs/.github

Organisation-wide defaults for [Lykoi Labs](https://github.com/lykoilabs):

- `profile/README.md` — the organisation profile shown on the org page.
- `SECURITY.md` — how to report a vulnerability (security@lykoilabs.dev).
- `CODE_OF_CONDUCT.md` — Contributor Covenant 2.1.
- `CONTRIBUTING.md` — what we accept right now and the clean-room rules.
- `.github/ISSUE_TEMPLATE/` and `.github/PULL_REQUEST_TEMPLATE.md` —
  default templates inherited by every repository without its own.

Repositories may override any of these by adding their own copy.
